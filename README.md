# 掼蛋在线 guandan-online

网页版掼蛋：**4 人在线对战 + 不限人数观战**。打开链接即可选择对战座位或观战。

## 快速开始

```bash
npm install
npm start          # 默认 http://localhost:3000 ，可用 PORT 环境变量修改
npm test           # 运行规则与流程测试
```

每次 push / PR 会在 GitHub Actions 上自动跑测试（`.github/workflows/test.yml`）。

1. 打开首页 → 输入昵称 → 「创建房间」，进入 `/r/房间号`
2. 点「复制链接」发给朋友，任何人打开 `http://<服务器>/r/房间号` 都可以：
   - 在空位点「坐下」成为玩家（1、3 号位为蓝队，2、4 号位为红队）
   - 不坐下即为观战（人数不限）。默认看不到手牌；点右下角「上帝视角」：「以玩家视角观看」画面和该玩家看到的完全一样（手牌、记牌器都按他的视角），只是不能操作牌；点座位头像或左右滑动手牌换人；也可选「四家手牌一览」：每家框里同时显示手牌和本轮出的牌（出牌条朝向牌桌中间，当前最大的一手金框标「最大」，不要的显示「不要」）；竖屏对家一行、上下家并排、自己一行，横屏上下家在两侧、对家和自己在中间一列。只对观战者生效，玩家拿不到
3. 人不够时，已入座的玩家可在空位点「加机器人」，或点「空位补机器人」一键补满
4. 4 人坐满后任一玩家点「开始游戏」

## 部署到 Render（免费）

仓库已包含 `render.yaml`：

1. 用 GitHub 账号登录 [Render](https://render.com)
2. **New → Blueprint**，选择本仓库，点 **Apply**
3. 部署完成后得到网址，如 `https://guandan-online.onrender.com`，房间链接为 `https://guandan-online.onrender.com/r/房间号`

之后每次 push 到 `main` 都会自动重新部署。

> 免费版闲置约 15 分钟后休眠，下次打开需等待 30–50 秒唤醒。服务器还有房间时会每 10 分钟自己访问一次保持唤醒，房间都散了才休眠。
>
> **不想重新部署时丢房间**：到 [Upstash](https://upstash.com) 免费建一个 Redis 数据库，把 REST URL 和 Token 填到 Render 后台的 `UPSTASH_REDIS_REST_URL`、`UPSTASH_REDIS_REST_TOKEN`，之后重新部署、休眠唤醒都会自动恢复进行中的房间。

## 功能

**规则**
- 标准两副牌 108 张，每人 27 张
- 全部牌型：单张、对子、三张、三带二、顺子、三连对、钢板、4~8 张炸弹、同花顺、天王炸
- 级牌大小（大于 A、小于王；顺子中按自然位置），A 可作顺子首尾
- 逢人配（红桃级牌）当任意非王牌；有多种解释时（如三带二）可选择
- 一轮无人要则出牌者继续；出完牌后由队友接风
- 升级：双下升 3 级、对手三游升 2 级、对手末游升 1 级
- 进贡 / 还贡：单贡（末游→头游）、双贡（大牌给头游，相同时头游下家贡给头游）；进贡须为最大的牌（逢人配除外），还贡须为 10 及以下；进贡者（双贡时贡大牌者）先出
- 抗贡：进贡方共持两张大王则免贡，头游先出
- 打 A：庄家队友非末游即胜出整场；打 A 失败 3 次退回打 2
- 报牌：剩 10 张及以下时头像旁张数变红，并提醒所有人
- 完整玩法说明见站内「📖 玩法说明」（`/rules.html`）

**对局**
- 机器人参战：开局前在空位添加/移除机器人，可 1 人 + 3 机器人单机练习
- 出牌计时（默认 30 秒，房间设置里可改）：超时自动出牌并进入托管，可随时取消
- 掉线：对局中掉线几秒后自动托管，不用每步干等；回来后自动取消
- 房间设置（「⋯」→「房间设置」，入座玩家可改，改动会在聊天里通知）：每步时限 15~90 秒、从几打起（开局前）、机器人难度（简单 / 普通 / 困难）、房间密码。设了密码后进房间（含观战）要输密码，「复制链接」会把密码带在链接 `#` 后面，朋友点开直接进
- 出牌记录：顶栏 📜，按轮列出这一局谁出了什么、谁不要（公开信息，玩家和观众都能看）
- 回放：一局结束后在结算页点「回放」，或之后在 📜 / 「⋯」里「回放上一局」，从起手牌逐手重看，四家手牌全部可见，可自动播放、拖动进度
- 战绩：大厅或「⋯」里「我的战绩」，记在本浏览器：局数、胜率、头游、双下、累计升级、整场胜负、最常出的牌型
- 互动表情：点别人的头像丢 🌹 👍 🍺 🥚 💣，所有人都能看到飞过去的动画（观众点头像还可以切到他的视角）
- 托管：与机器人同一套 AI，自动进贡、还贡、出牌。AI 基于「手牌规划」：每一步评估出完后剩余牌最少还要几手，优先出不破坏牌型的牌；不压队友、队友快走完时喂小牌；炸弹和大牌留着抢出牌权，对手快走完或自己三手内能走完时才炸（同牌对打对上一版胜率约 70%）。机器人难度：困难即上述 AI；普通偶尔会按简单策略出牌；简单只会出最小的能出的牌（同牌对打：困难对简单约 85%，困难对普通约 72%）
- 提示：按从小到大循环给出能出的牌
- 聊天：玩家和观众都可发言，带快捷语
- 头像：大厅或房间里点「头像」上传图片，自动裁成正方形并压缩到约 5KB；未上传时显示名字首字，机器人显示 🤖
- 服务端权威校验，防止客户端作弊；断线刷新后自动回到原座位
- 手牌按点数竖向成列（参考主流掼蛋 App），炸弹、同花顺、逢人配自动排在最左并用色条标出
- 理牌：选中几张牌点「理牌」可组成自定义列放到最左；「一键理牌」把整手牌自动拆成顺子、钢板、三连对、三带二、对子、单张等组合（搜索出牌手数最少的拆法，炸弹和同花顺不拆），再点一次「按点数排」恢复；「同花顺」循环选中手里的同花顺
- 点按或按住滑动可连续多选
- 手机/桌面自适应，牌面按屏幕尺寸自动放大；手机横屏和 800 像素左右高的电脑屏为紧凑布局（左右两家放两侧，头像与名字横排），手牌永远不会盖住头像
- 界面：深蓝主题；顶栏只保留返回、房间号、复制链接、聊天和「⋯」菜单（改名、头像、暂停、存档、读档、返回大厅）；比分牌显示两队级数与当前打几
- 存档 / 读档：对局中点「⋯」→「存档」得到加密存档码（自动下载文件，本浏览器也留一份），对局随即暂停；之后在任意房间「读取存档」，坐满（可换人、可用机器人补位）后点「继续对局」。存档码由服务器密钥加密，看不到也改不了里面的手牌
- 暂停：暂停期间可以换座、换人、加减机器人
- 记牌器（仅观战者）：顶栏 🃏 开关，显示大小王、级牌、A…2 还剩几张（上帝视角看某位玩家时：除去已出和他手里的；否则为还没出的）。玩家看不到，服务器也不会把出牌统计发给玩家
- 倒计时：轮到谁，谁的头像外圈出现缩短的圆环，最后 5 秒变红闪烁
- 炸弹特效：出炸弹 / 同花顺 / 天王炸时弹出大字横幅，牌桌震动
- 手机竖屏和横屏都整屏固定，不用上下滑动；出牌按钮只在轮到自己时浮现（竖屏浮在自己头像上方，横屏与头像同一行），平时把空间让给手牌和牌桌；托管按钮在底部工具栏，托管中显示「取消托管」
- 选中的牌向上弹起；「不要」和聊天消息以气泡显示在玩家旁
- 出牌动画：牌从出牌人方向飞入桌面
- 牌面：J/Q/K 金框图案、大小王 JOKER 字样、右下角倒置角标；对手位置显示一叠牌背和张数
- 音效（Web Audio 合成，无需音频文件）：出牌、不要、炸弹、轮到自己、最后 5 秒倒数、胜负
- 结算页：胜负、升级动画、四家名次、下一局进贡安排
- 设置（「⋯」→「设置」）：牌面大小（小/中/大）、桌面颜色（蓝/绿/紫）、音效开关、出牌二次确认
- 大厅：「和机器人练习」一键开局；显示最近去过的房间
- 可安装到手机桌面（PWA）：浏览器菜单「添加到主屏幕」，之后全屏打开、没有地址栏；对局中屏幕保持常亮（浏览器支持时）

**配置（环境变量）**

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 端口 |
| `TURN_SECONDS` | 30 | 每步操作时限 |
| `DATA_FILE` | 未设置 | 设置后房间定期保存到该 JSON 文件，重启后恢复 |
| `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | 未设置 | 设置后房间保存到 Upstash Redis（优先于 `DATA_FILE`），适合没有磁盘的 Render 免费版 |
| `OFFLINE_AUTO_MS` | 8000 | 对局中掉线多久后自动托管（毫秒） |
| `KEEP_ALIVE` | 开 | 设为 `0` 关闭保活自访问（Render 上自动用 `RENDER_EXTERNAL_URL`，其他平台可设 `KEEP_ALIVE_URL`） |
| `SAVE_SECRET` | 随机 | 存档码加密密钥；不设置则重启后旧存档失效（`render.yaml` 已自动生成） |

> Render 免费版没有持久磁盘，`DATA_FILE` 只在自建服务器或挂了磁盘的付费实例上有意义；Render 免费版请用 Upstash。

## 结构

```
shared/rules.js   规则引擎（牌型识别、比较、升级），前后端共用
shared/arrange.js 理牌（手牌分列）
shared/hint.js    出牌提示 / 托管用的组合搜索，前后端共用
shared/replay.js  回放：由起手牌 + 出牌记录还原每一步
server/game.js    对局状态机（进贡、出牌、升级）
server/ai.js      机器人 / 托管出牌策略
server/room.js    房间：座位、聊天、计时、暂停
server/save.js    存档码加密/解密
server/avatars.js 头像校验与提供（内存，按内容哈希）
server/persist.js 房间持久化（Upstash Redis / 本地文件）
server/index.js   Express + Socket.IO：连接、广播、持久化
public/app.js     前端入口（原生 JS 模块，无需构建）
public/js/        前端模块：room（房间页主逻辑）、lobby、cards、layout（手牌尺寸）、fourHands（四家一览）、
                  replayView、logPanel、stats、emotes、roomSettings、sfx、settings、avatar、util
public/rules.html 玩法说明
public/sw.js      PWA：manifest.webmanifest + sw.js 支持安装到桌面
test/             node:test 测试
```
